# Rent-Roll Reels — Record-Day Checklist

Batch-produce all 8 Reels in one sitting. Order matters: build the reusable assets
first, gather footage once, then assemble on an assembly line. Budget ~3–4 hours.

Companion to: `instagram-reels-scripts.md` · `instagram-reels-shot-list.md` · `instagram-reels-asset-templates.md`

---

## Phase 0 — Prep (once, ~30 min)
- [ ] Build the 3 reusable assets → **brand card**, **bar chart**, **number counter** (see asset-templates doc). Save each as a CapCut draft + Canva template.
- [ ] Install fonts: **Anton** (display) + **Inter** (captions/data).
- [ ] Confirm the 9:16 project preset (1080×1920) and safe-zone guides on.
- [ ] **Verify the two flagged stats** before anything else:
  - Reel 3 — "47 of 50 metros" → check latest Zumper / Apartment List report; swap in real numbers.
  - Reel 8 — make-ready / vacancy math → plug in real figures for an $1,800 unit.
- [ ] Pick 3–4 **trending audios** now (save them in the app): 1 tense/build, 1 upbeat lo-fi, 1 news/urgent. Match to script audio notes.

## Phase 1 — Gather footage (once, ~45 min)
- [ ] Make 8 folders named `Reel 1`…`Reel 8`.
- [ ] Work down the **shot list**; download 3–4 vertical clips per Reel into its folder.
- [ ] Screen-record / phone-shoot the 📱🎬 beats in one pass (spreadsheet scroll, phone-in-hand, listing browse).
- [ ] Quick reject: any clip with a face, another brand's logo, or fast/jittery motion.

## Phase 2 — Assemble (assembly line, ~1.5–2 hr)
Do the **same step across all 8** before moving to the next — it's far faster than finishing one Reel at a time.
- [ ] **Round 1 — timeline:** drop each Reel's clips in beat order, trim to the script's timings, append the brand card.
- [ ] **Round 2 — text:** add on-screen text per beat (Anton, bone, upper-middle third, inside safe zone). Emphasis phrases → accent pill.
- [ ] **Round 3 — data/money beats:** drop in the bar-chart template (Reel 3) and counter template (Reels 1, 8); swap numbers/colors.
- [ ] **Round 4 — audio:** add the matched trending sound; sync text beats to the hits; duck/remove clip audio.
- [ ] **Round 5 — polish:** consistent transitions (hard cuts or a single subtle style), loop check (last frame → first frame reads clean).

## Phase 3 — Per-Reel QA (before export)
Run this on each:
- [ ] **Hook readable in frame 1** (first ~1s), no scrubbing needed.
- [ ] All text **inside safe zones** — nothing under where caption/buttons sit (top 250 / bottom 400 / right 110px).
- [ ] Spelling + numbers correct; the two verified stats are the real ones.
- [ ] One idea per beat; nothing on screen too long to read or too short to catch.
- [ ] Brand card present; handle correct.
- [ ] Length 9–18s; ends on save/comment CTA.
- [ ] Export **1080×1920, .mp4, ≥30fps**.

## Phase 4 — Caption & publish
For each Reel, from the script:
- [ ] Paste caption; **front-load the hook** in the first line (before the "…more" cutoff).
- [ ] End caption with the **one question** (comment-bait).
- [ ] Add the Reel's hashtags (script has them).
- [ ] Set the **cover** — grid thumbnail with the 2–4 word cover text; keep covers consistent so the profile grid looks intentional.
- [ ] Schedule, don't dump: **1 Reel/day across ~2 weeks** beats posting 8 at once. Consistency is the reach lever.
- [ ] Suggested slots: Mon/Wed/Fri + one weekend; post when your audience is active (check Insights).

## Phase 5 — Track (the whole point)
- [ ] After ~72h, log each Reel's **views, reach (followers vs non-followers), saves, shares, follows**.
- [ ] Compare Reel reach vs your recent **static** posts — this confirms the format fix.
- [ ] Note the top pillar/hook; make the next batch more of what saved + shared best.

---

### One-glance flow
Assets → footage → assemble (line, not one-by-one) → QA → captions → schedule 1/day → track at 72h.
