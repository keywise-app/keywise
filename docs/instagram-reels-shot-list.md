# Rent-Roll Reels — Stock-Footage Shot List

Companion to `instagram-reels-scripts.md`. Per beat: concrete search terms to paste
into a stock site, so cutting each Reel is a find-and-drop job.

## Where to pull (all faceless-friendly)
- **Free:** [Pexels](https://pexels.com/videos), [Pixabay](https://pixabay.com/videos), [Mixkit](https://mixkit.co) — good coverage for houses, money, desks, phones.
- **Paid (better/rarer clips):** Storyblocks, Envato Elements, Artgrid.
- **Shoot yourself (fastest for these):** any beat marked 📱 (screen-recording) or 🎬 (10-sec phone clip) — a spreadsheet scroll or a hand on a phone is quicker to film than to find, and looks more authentic.

## Rules for every clip
- **Vertical 9:16** (or crop-safe center). Filter to "vertical" where the site allows.
- **No faces / no recognizable people** — hands, backs, objects, wide shots only (keeps it faceless).
- **Slow, calm motion** — push-ins, pans, tabletop. Avoid fast/branded clips.
- **~2–3s per clip**, slightly longer than the beat so you can trim.
- **No visible other-brand logos** (app icons, competitor UI).
- Keep 3–4 clips max per Reel; reuse the **brand card** (your RR outro) on every one.

## Fast-cut workflow
1. Batch-download 3–4 clips per Reel into a folder named by Reel #.
2. In CapCut/Reels: drop clips → add the on-screen text beats from the script → sync to trending audio → append brand card.
3. **Reusable assets to make once:** the RR brand-card outro, a bar-chart motion template (Reel 3), and a number-counter template (Reels 1 & 8). Then every future data/money Reel is a copy-paste.
