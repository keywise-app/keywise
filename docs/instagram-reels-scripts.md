# Rent-Roll Instagram — Reels Scripts (faceless)

**Why this file exists:** the account's high-view posts were **Reels**; views dropped
when content shifted to **static graphics / carousels**. Reels reach ~2–3× more
non-followers, so **Reels are now the discovery format.** Carousels stay as the
save-and-convert layer (see `instagram-content-queue.md`), but reach starts here.

Topical & educational only — **never** real tenant or rent-roll data from the app.

## Faceless Reel formula (every script follows it)
- **7–15s** is the sweet spot for reach on faceless text-reels. Loop-friendly.
- **Hook on screen in the first 1 second** — before the viewer decides to scroll.
- **No talking head:** on-screen text synced to audio beats, over b-roll
  (stock house/key/money footage, screen-recordings, or simple motion cards).
- **Trending audio, low competition** — pick a rising sound the day you post;
  audio type is suggested per script, swap for whatever's trending.
- **The detail lives in the caption**, not the video. That's where the old
  "detailed" format that you liked now goes — video hooks, caption delivers.
- **End on a save/comment prompt** — saves + comments are ~3× a like for reach.

## Reusable template (for the next scripts)
1. **Hook (0–1s):** contrarian claim, mistake warning, or list tease — the single most self-relevant line.
2. **Tension (mid):** 2–3 beats that widen the curiosity gap, one idea per beat.
3. **Payoff/CTA (last 2s):** resolve it + "save this" or a comment prompt.
4. **Caption:** deliver the full value here; end with one question.
5. **Cover:** 2–4 words, big — this is your grid thumbnail.

## Posting notes
- **Cadence beats everything.** 4–5 Reels/week, consistent days, is worth more than sporadic bursts. Erratic posting is a top reach-killer.
- **Test format as the variable:** post Reel 1–3 and compare reach to the recent static posts. If Reels win (they should), Reels become the default and carousels are for saves only.
- **Recycle winners:** any Reel that overperforms → remake as a carousel for the save layer, and vice versa.
