# Rent-Roll Reels — Royalty-Free Image Sources

Vetted places to pull **free, commercial-use** photos for the hero shots, with
theme-matched deep links per Reel. Companion to `instagram-reels-shot-list.md`.

## Best sources (zero attribution, commercial OK)
| Source | License in plain English |
|--------|--------------------------|
| [Pexels](https://www.pexels.com) | Free for commercial & personal use, **no attribution required**, edits allowed. Don't resell unaltered, don't imply endorsement by people/brands shown. |
| [Unsplash](https://unsplash.com) | Free for commercial & personal use, **no permission/attribution needed**. Can't compile the library to build a competing stock service. |
| [Pixabay](https://pixabay.com) | Free, commercial OK, **no attribution**. Some limits on identifiable people/property and redistribution. |

**CC0 / public-domain (may need attribution — check each item):**
[Openverse](https://openverse.org) · [Rawpixel CC0](https://www.rawpixel.com/search/cc0) · [Wikimedia Commons](https://commons.wikimedia.org)

## Faceless-brand cautions
- **Avoid recognizable faces** — it's a faceless account; use exteriors, hands, objects, wide interiors.
- Don't use a photo of an identifiable person or private property in a way that implies they endorse the product.
- The Pexels/Unsplash/Pixabay licenses cover commercial IG use — you're fine for this.

## Getting them into the preview / production
- **For CapCut/Reels (production):** download directly on your machine and drop into the editor. This is the real path — no size limits, full-res.
- **For the HTML preview (optional):** the preview needs images embedded as data URIs. Drop the ones you like into the chat, or add them to the repo (e.g. `public/reel-photos/`), and they get baked into the preview so the hero shots become real photography.
- **Sizing tip:** for the preview, ~1080×1920 JPGs at moderate quality keep the file small; full-res is fine for CapCut.
